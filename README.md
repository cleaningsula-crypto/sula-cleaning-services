# Sula Cleaning Services — Website

## Quick start
```bash
npm install
npm run dev
```

## Deploy (Free) on Vercel
- Push this repo to GitHub
- Go to Vercel → New Project → Import your repo → Deploy

## Calendly + Google Calendar blocking (recommended)
Use Calendly connected to cleaningsula@gmail.com so busy slots are blocked automatically.
Then paste your Calendly link in `app/page.tsx`.
